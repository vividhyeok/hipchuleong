# Hipchuleong

이미지를 붙여넣거나 업로드한 뒤, 마우스·터치·펜으로 눌러 말랑하게 변형하는 반응형 웹 물리 장난감입니다.

- PC: 붙여넣기(Ctrl/Cmd+V), 드래그 앤 드롭, 파일 업로드
- 태블릿/스마트폰: 사진 업로드, 터치/펜 상호작용
- Canvas 기반 스프링 메쉬 물리
- PNG 스냅샷 저장
- 지원 브라우저에서 WebM 녹화
- 설치 가능한 PWA

## 실행

정적 파일만 사용하므로 저장소 루트에서 바로 호스팅할 수 있습니다.

```bash
python -m http.server 8080
```

그 후 `http://localhost:8080`에 접속하세요.
